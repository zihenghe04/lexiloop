# LexiLoop 划词翻译

一个可直接加载的 Chrome Manifest V3 扩展，做划词翻译、英文 PDF 对照阅读和个人词库。当前版本为 `0.27.1`，版本记录见 [CHANGELOG.md](CHANGELOG.md)。
需要 Chrome 119 或更高版本。

## 已实现

- 普通网页、Notion 类 `contenteditable`、`input` 和 `textarea` 划词翻译
- 划词悬浮窗可关闭，关闭后快捷键仍能读取当前选区
- 自定义 Chrome 快捷键或右键菜单翻译
- 内置 PDF.js 阅读器，支持可选文字层、连续滚动、页码跳转、缩放（含触控板双指捏合，以指针为中心）、远程 URL 和本地文件
- 划词选区与原文字形对齐：透明文字用 PDF 内嵌字体，两端对齐的宽度差记到词间距；拖选经过引用链接时选区不再跳行
- 阅读器顶栏分三区（文档、阅读模式、工具），低频操作收进“更多”菜单；侧栏上方是本文导航，下方“我的学习”直达词库、复习和文献库并显示数量
- 网页 PDF 可选自动进入 LexiLoop 阅读器，兼容 `.pdf` 链接和由响应头声明的无后缀 PDF 地址
- PDF 左侧支持页面缩略图、文档原生大纲、批注和本文生词，并可下载原文件或打印全部页面
- PDF 阅读模式分“仅原文 / 原文译文 / 仅译文”，译文从当前页附近排队翻译，可暂停或只翻当前页；“版面对照”把本页译文覆盖在原版面上
- PDF 支持拖拽截图问 AI，以及带当前页和相关页面上下文的右侧连续问答；同一 PDF 可新建、切换、删除多个对话并自动恢复
- PDF AI 侧栏支持拖动左边缘调整宽度，尺寸会保存在本机；双击边缘或按 `Home` 可恢复默认宽度
- PDF AI 可使用独立模型，回答支持安全渲染 Markdown、表格、代码块与 LaTeX 数学公式
- PDF 文献库支持本地文件、PDF 网址、DOI、arXiv 和 BibTeX 智能导入，按论文身份去重，并可搜索筛选、收藏、编辑元数据和继续阅读
- 文献库支持本地全文索引与跨文献检索，命中结果显示页码和片段并可直接跳回原文；索引可逐篇重建、删除或统一清理
- 阅读器可一键将当前 PDF 加入文献库，并自动保存当前页、阅读进度与最近阅读时间；本地 PDF 原文件持久保存在 IndexedDB
- PDF 选区高亮、下划线、删除线和批注笔记，按文档持久保存；页面标记可点击编辑，左侧批注列表可直接定位或删除
- 英文词典结果显示英美音标、词性、分义和发音按钮
- 翻译服务适配层：词典查询与文本翻译分离，支持内置降级和自定义模型连接
- 模型连接列表：可增删的连接，协议支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages，另有 ChatGPT 与 Grok 订阅登录；可从 CC Switch 导入 API Key，可拉取模型列表
- 翻译和 PDF AI 分别选择连接、模型和推理强度；设置中可查看脱敏请求与原始响应
- 翻译成功后自动收录，并记录累计次数、来源、上下文和精确时间
- 词库搜索、按次数/时间/字母排序、删除、JSON 导出和间隔复习

## 安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库根目录（含 `manifest.json` 的那一层）。

界面源码在 `ui/`，构建产物在 `ui-dist/`。直接加载仓库根目录即可使用，不需要先构建。修改 `ui/` 后需要运行 `npm --prefix ui install && npm --prefix ui run build`。

更新文件后，在扩展管理页点击 LexiLoop 的刷新按钮。建议固定扩展图标，点击图标会打开右侧个人中心。

## 快速开始

装好后先跑通这三件事。每一步的细节都在后文的「使用」里。

### 一、网页划词翻译

1. 打开任意英文网页，选中一段文字。
2. 点旁边出现的「译」，或者按 `Alt+Shift+T` 翻译当前选区。
3. 单个英文单词会显示英美音标、词性和分义，并带发音按钮。

翻译成功会自动进词库。在 Notion 这类富文本编辑器、输入框和文本域里同样可用。

### 二、读一篇英文 PDF

1. 点扩展图标打开右侧面板，再点顶部的 PDF 图标填入 PDF 网址；本地文件在阅读器顶栏「更多」里打开。
2. 顶栏切到「原文译文」：左边原文，右边按段落重排的译文，两栏滚动和点击互相定位。
3. 译文从当前页附近排队翻译，进度旁可以暂停，或只翻当前页。
4. 选中原文文字，悬浮工具栏可以翻译、高亮、下划线和写批注；右侧「AI 助手」可以针对当前页、截图或全文提问。

### 三、管理学习记录

| 页面 | 能做什么 |
|---|---|
| 词库 | 搜索、按次数/时间/字母排序、删除、导出 JSON |
| 复习 | 间隔复习，空格显示答案，按 `1` `2` `3` 评分 |
| 文献 | PDF 文献库：DOI / arXiv / BibTeX 导入、收藏、全文检索、继续阅读 |

面板顶部在四页之间直接切换；PDF 阅读器侧栏底部的「我的学习」也会跳到这里。

## 使用

### 网页与可编辑区域

选中不超过 500 个字符的文本，点击旁边出现的“译”。在 Notion、富文本编辑器、输入框和文本域里同样可用。翻译成功后会自动进入词库，同一词条会累计次数并保存本次来源。

在个人中心右上角打开“设置”，可以关闭划词悬浮窗。这个开关只影响自动出现的按钮，不影响快捷键和右键翻译。

文本翻译默认使用内置自动切换，也可以改用自己的模型连接（见下一节）。连接测试固定发送 `Hello, world.`，诊断中的认证头会被脱敏。PDF AI 默认启用 SSE 流式输出，不支持流式的接口会自动回退为完整 JSON；PDF AI 模型留空会继承翻译模型，截图解释需要所选模型支持图片输入。

### 模型连接

设置里的“模型连接”是一份可以增删的列表，每条连接有自己的名称、协议、地址、模型和 API Key：

- **自定义 API**：从 OpenAI、Anthropic、OpenAI Responses、DeepSeek、Anthropic 兼容服务（示例）等起点新建，地址和模型都能改。协议支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。点“拉取模型列表”会读取同一服务的 `/models`，作为两个模型框的候选。
- **订阅登录**：ChatGPT（Codex 订阅）和 Grok（xAI 设备码登录），通过本机辅助程序登录，不需要 API Key。
- **从 CC Switch 导入**：读取 CC Switch 的数据库，预览后选择要导入的 API 连接。

列表上方的“翻译使用 / AI 使用”分别选一条连接，改了立即生效；下方编辑的是选中的那条连接，保存不会改掉上面的选择。每条连接里，翻译和 PDF AI 各有自己的模型和推理强度（订阅连接的翻译模型留空时与 AI 相同）。Anthropic Messages 的推理强度以 `output_config.effort` 发送，OpenAI 两种协议分别用 `reasoning_effort` 和 `reasoning.effort`。

新装或未配置时不会默认出现内置连接：没有连接也能用内置的免费翻译，需要问 PDF 或用自己的模型时再点「添加连接」。旧版本留下的“原方案”只有在真的配过密钥时才会继续显示；密钥本身保留在本机。推理强度在 0.24 之前翻译和 AI 共用一个值，升级后两边都沿用这个值。API Key 只保存在本机 `chrome.storage.local`，界面上只显示“已保存在本机”，不会回显明文。

请求由插件后台直接发出。Messages 协议的 system 使用顶层字段，截图使用 base64 image block，回答合并所有 text block，thinking 与工具事件不会显示为答案；协议必填的 `max_tokens` 可在高级设置中调整。

### PDF

Chrome 内置 PDF 查看器不允许扩展内容脚本注入，因此无法直接在原查看器内部显示自定义悬浮窗。LexiLoop 提供内置阅读器解决这一限制：

1. 点击个人中心顶部的 PDF 图标，输入 PDF 网址，或在阅读器顶栏“更多”菜单里打开本地文件。
2. 开启“增强 PDF 阅读”后，直接打开网页 PDF 会自动进入 LexiLoop 阅读器；无 `.pdf` 后缀但响应头正确的下载地址也会被识别。
3. 阅读器支持连续上下滚动、左侧缩略图/大纲导航、页码跳转和缩放；触控板双指捏合或 `⌘/Ctrl` + 滚轮以指针为中心缩放，停手后按新比例清晰重绘。下载和打印在顶栏“更多”菜单里。
4. 顶栏中间切换“仅原文 / 原文译文 / 仅译文”。译文从当前页附近开始排队翻译，可以暂停或只翻当前页；“版面对照”把本页译文覆盖在原版面上。
5. 选中 PDF 文字后，会显示统一的翻译、高亮、下划线和笔记工具栏；翻译结果与批注工具互斥显示。点击已有标记可修改样式、颜色和笔记，也可在编辑弹窗或左侧“批注”页删除。
6. 在阅读器中可以像普通网页一样划词、点击悬浮窗或直接使用快捷键。
7. 点击顶部截图图标后，在原始 PDF 页面拖拽框选，截图会发送到已配置的 OpenAI 兼容模型并在右侧解释；模型需要支持图片输入。
8. 点击顶栏“AI 助手”打开 PDF AI，可连续提问。使用标题栏的加号新建对话，列表按钮可切换或删除当前 PDF 下的历史对话。当前页和截图问题只读取当前页；具体问题检索最多四个相关片段；全文总结使用文档地图、摘要/引言/结论和稀疏代表页。回答支持 Markdown 和 `\(...\)` / `\[...\]` LaTeX 公式。
9. PDF AI 标题栏的设置按钮可直接打开服务设置。填写“PDF AI 模型”即可与翻译模型分开；留空则继承翻译模型。
10. 拖动 PDF AI 侧栏左边缘可调整宽度，宽度会自动保存。侧栏边缘获得焦点后也可用左右方向键调整，按 `Home` 或双击恢复默认宽度。

### PDF 文献库

个人中心的“文献”页集中管理论文和 PDF。点击“添加 PDF”导入本地文件；“智能导入”接受 PDF 网址、DOI、arXiv ID/网址或一条 BibTeX 记录。DOI 会通过 Crossref、arXiv 会通过官方 Atom API 获取标题、作者、年份、期刊/会议、摘要、关键词和来源信息；BibTeX 在本机解析，不调用 AI。

重复条目依次按 DOI、arXiv ID、PDF 内容指纹和来源网址识别。再次导入会补齐缺失字段，并保留已有标题、标签和笔记。文献行的元数据按钮可以按 DOI 或 arXiv 再次补全；只有元数据而没有可用 PDF 的记录会显示“查看来源”，不会错误进入阅读器。

文献列表可搜索标题、作者、DOI、arXiv、标签、摘要和笔记，并按阅读状态、收藏、最近阅读、添加时间、进度或标题筛选排序。每条文献可编辑标题、作者、年份、期刊/会议、出版方、DOI、arXiv、引用键、来源网址、摘要、标签、笔记和阅读状态。点击“继续阅读”会恢复上次页码，阅读器滚动后会自动保存进度；阅读到最后一页会标记为已读。

同一个搜索框也会检索已经建立索引的 PDF 正文。正文命中显示页码和上下文片段，点击即可在阅读器中打开对应页。文献行可建立、重建或删除索引；文献库顶部可查看索引文档数、页数和字符数，也可以清理全部索引。文字过少的扫描版 PDF 会明确标记为“需要 OCR”。

在阅读器顶栏“更多”菜单里点“加入文献库”，也可以把当前打开的 PDF 直接入库；侧栏底部“我的学习”可直接打开个人中心的词库、复习和文献库。PDF 内嵌的标题、作者、年份、主题和关键词会在可用时自动补充，手动编辑过的内容会被保留。

本地 `file://` PDF 受 Chrome 单独的文件访问权限控制，需要在 LexiLoop 阅读器里点击“打开本地 PDF”。如果继续使用 Chrome 原查看器，仍可复制选区后按快捷键，或使用右键翻译作为兜底。

### 快捷键与发音

默认快捷键为 `Alt+Shift+T`。在个人中心的设置面板中可以查看当前按键，并打开 Chrome 快捷键页自行修改。

英文单词和短语结果旁会显示发音按钮：优先播放词典音频，音频不可用时回退到系统语音合成。

## 数据与翻译服务

- 词库、文献元数据、交互设置、PDF AI 对话历史和 API Key 保存在当前 Chrome 配置的 `chrome.storage.local` 中；API Key 不会写入同步存储，但本地存储本身不等同于加密保险箱。
- 导入文献库的本地 PDF 原文件保存在扩展自己的 IndexedDB 中，不会上传；从文献库删除本地文献时会同时删除该文件。网页 PDF 只保存来源网址。
- 使用 DOI 或 arXiv 智能导入/补全时，只会把相应标识符发送给 Crossref 或 arXiv 官方元数据接口；BibTeX 解析完全在本机完成。
- 翻译服务的非敏感配置保存在 `chrome.storage.sync`，登录同一 Chrome 账号时可同步到其他设备。
- 英文单词优先使用有道词典；短语和句子默认依次使用 MyMemory 与 Google Translate。选择自定义模型连接后会优先调用该连接，并可按设置回退到内置服务。
- 远程 PDF 阅读和自动识别需要扩展读取 PDF 地址及主文档响应头；下载功能需要 Chrome 下载权限。因此首次更新到 `0.5.x` 或更高版本时 Chrome 可能重新显示权限确认。
- PDF 对照翻译会调用当前翻译服务，但不会把整页内容自动收录为词条；只有划词查词仍会自动收录。
- PDF AI 只使用“AI 使用”所选的连接（自定义 API 或订阅登录），不会回退到 MyMemory 或 Google。提问时只发送选中的截图、问题、按总字符预算裁剪的近期对话和本地检索出的 PDF 片段，不会写入词库。具体问题上下文约 14,000 字符，全文总结约 20,000 字符，对话历史最多约 8,000 字符。多个对话按 PDF 指纹在本机保存，并限制近期文档、会话、消息与总容量；截图图片本身不会写入长期历史。
- 这些公共接口适合个人原型，不适合正式商业发布。正式版应替换为有密钥、配额和服务条款保障的翻译 API。

## 隐私

哪些数据存在本机、哪些内容会发送到第三方服务，见 [PRIVACY.md](PRIVACY.md)。摘要：词库、文献、批注、PDF 原文件和 API Key 都只保存在本机；只有触发翻译或提问时，相应文本才会发送到你配置的服务。
